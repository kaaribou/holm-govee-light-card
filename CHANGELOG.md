# Changelog

## 1.4.0
- Première version publique : **HOLM Govee Light Card** (dépôt renommé `holm-govee-light-card`, fichier `holm-govee-light-card.js`).
- **Vignettes de scènes générées par défaut** : les images de l'application Govee deviennent facultatives ; une image absente est remplacée automatiquement par la vignette générée. Nouvelle option `scene_images`.
- Nom de la carte dans le sélecteur : « HOLM Govee Light Card ». L'ancien type `custom:govee-like-light-card` reste accepté.

## 1.3
- Carte minimale quand la lumière est éteinte, panneaux repliables, glissements fluides, aperçu de la couleur en direct, nouveau nom d'élément `custom:holm-govee-light-card`.
